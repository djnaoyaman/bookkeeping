# IL MASTROの学習イベント

2026年11月23日更新。送信先は `G-837HXKXW8Q`。

## 今回追加したイベント

| イベント | 発火条件 | 送信する教材情報 |
|---|---|---|
| learning_start | 講義演習の問題画面を開き終えたとき。模試は新しい回の保存と画面表示に成功したとき | learning_type と item_id |
| learning_complete | 講義演習で有効な回答の採点結果を表示したとき。模試は回答確定または時間切れの結果が保存され、結果を表示したとき | learning_type と item_id |

`learning_type` は `course_exercise` または `mock_exam` の固定値です。前者の `item_id` は教材にある問題ID、後者は `nissho3_mock_01` です。模試の試行UUID、回答、得点、正誤、学習者情報は送りません。講義演習のcompleteは採点結果表示を表し、教材全体の修了や合格を意味しません。

初期表示、講義の自動復元、模試の再開・過去結果表示ではstartを送りません。未入力などの採点不能、保存失敗ではcompleteを送りません。講義演習の既存submittedガードと模試の状態遷移により、同じ確定を重複計測しません。

## 既存計測

通常の反復演習は `practice_start`、`answer_submit`、`practice_complete`、`mistake_retry_start` 等で計測済みです。同じ操作に同義イベントを加えていません。

## 実装箇所

`dist/discovery.js` が新イベント名・学習種別・教材IDの書式を限定し、`send_to` とクエリを除いたページ情報を付与します。`dist/learning-course.js` と `dist/mock-ui.js` は実際の成功箇所から呼びます。既存のGA無効フラグを尊重し、送信処理の失敗を学習処理へ伝えません。

これらのJSは既存のHTML生成処理が参照する実装ファイルです。生成処理はこれらのJSを上書きしないため、再生成してもhooksを保持します。

## 送信範囲

計測先はこのサイトの既存GA4ストリームに限定します。新しいGoogleタグやconfigは追加していません。自由入力、検索語、回答本文、氏名、URLのクエリやハッシュを追加イベントのパラメータに含めません。自動page_view・scroll・外部リンク計測と同義のイベントも追加しません。

## 確認方法

Googleへの実送信を伴わない局所検証と、既存CIを使います。公開後の確認は変更した資産と代表ページに限定します。送信コードの確認と、GA4管理画面での受信確認は区別します。
